# LiveText Scanner

Real-time camera OCR: a client-side PWA (Tesseract.js), an Android app (Kotlin, CameraX + ML Kit), and a desktop Python version.

**Live app:** https://ubaid792792.github.io/live-text-scanner/

## How to use

- **PWA:** open `index.html` (live link) on a phone and allow camera access. See `PWA-README.md`.
- **Android:** open `android/` in Android Studio and run.
- **Desktop:** `python3 desktop_livetext_scanner.py`.

## Privacy

No API keys or personal data are stored in this repository.
